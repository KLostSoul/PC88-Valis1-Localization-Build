# 확정 소스 경계

이 디렉터리는 한글패치 재현 빌드에 실제로 사용되는 검토 완료 소스를 보관합니다. 원문·한글 번역·제어 바이트·주소 범위·D88 raw 표는 각각 명시적으로 유지하며, 타이틀 로고는 `GFX/`의 흑백 PNG를 실제 이미지 입력으로 받습니다. `tables/logo/source-map.csv`가 이미지와 그룹·plane·RAM 영역·해상도·인코더를 선언합니다.

빌더는 완료본에서 새 표를 추출하거나 토큰을 자동 매핑하지 않습니다. 로고 PNG가 편집되면 source-map 설정에 따라 061F/05CE 인코더와 RAM-to-raw 대응표로 원본 D88의 같은 길이 영역을 갱신합니다. 편집하지 않은 기본 로고는 검토된 `tables/logo/raw-changes.csv`를 사용해 기준 출력을 보존합니다. 리터럴 변경 행은 원본 바이트, 근거 문서 위치, 길이, 종결자와 물리 저장 위치를 가집니다.

완료 바이너리·IPS·비교용 이미지·프로젝트 원문 문서는 빌드 입력이 아닙니다. `GFX/`의 로고 편집 PNG만 그래픽 이미지 입력으로 사용하며, 원본 D88/KANJI1 ROM 및 생성한 매체 이미지는 로컬 입력·출력으로만 관리하고 저장소에 넣지 않습니다.
