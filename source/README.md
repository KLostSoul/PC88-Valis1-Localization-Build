# 확정 소스 경계

이 디렉터리는 한글패치 재현 빌드에 실제로 사용되는 검토 완료 소스를 보관합니다. 원문·한글 번역·제어 바이트·주소 범위·D88 raw 표는 각각 명시적으로 유지하며, 타이틀 로고는 `GFX/`의 흑백 PNG를 실제 이미지 입력으로 받습니다. `tables/logo/source-map.csv`가 이미지와 그룹·plane·RAM 영역·해상도·인코더를 선언합니다.

빌더는 완료본에서 새 표를 추출하거나 토큰을 자동 매핑하지 않습니다. 로고는 PNG 여섯 장을 source-map 설정에 따라 061F/05CE로 매번 인코딩하고 RAM-to-raw 대응표를 거쳐 원본 D88에 기록합니다. raw 변경 행은 원본·변경 바이트와 물리 위치를, 텍스트 표는 문자·토큰·길이·종결자를 기록합니다.

이벤트 표는 문자·제어 단위로 한 행을 사용합니다. 행 안의 바이트 배열은 공백으로 구분하며 주소, 이전 값, 변경 값이 같은 순서로 대응합니다.
