# 재현 빌드 계층 구조

이 한글패치 재현 빌드는 원본 매체 검증, 수동 확정 소스, Python 직접 기록, 출력 검증의 계층으로 구성됩니다.

## 분석 계층

`analysis/evidence-ledger.json`에는 무엇을 어디에서 관찰했고 어떤 검토를 거쳤는지 기록합니다. 기록되어 있다는 이유만으로 빌드 소스가 되지는 않습니다.

## 확정 소스 계층

`source/`에는 검토가 끝난 리터럴 바이트와 대응표, 편집 로고 PNG를 둡니다. `source/tables/logo/source-map.csv`가 PNG별 그룹·plane·RAM source 범위·인코더 설정의 빌드 기준입니다. 모든 바이트 기록은 분석 근거와 원본 D88/ROM 위치를 유지합니다.

## 직렬화·빌드 계층

D88 파서는 트랙·섹터·payload·실제 파일 오프셋을 확인합니다. 직접 바이트 기록기는 명시된 old/new 값을 원본 복사본에 씁니다. 로고 PNG 여섯 장은 매번 설정표에 선언된 인코더로 source stream을 만들고, RAM-to-raw 대응표를 통해 payload에 적용합니다.

## 검증 계층

검증 단계는 D88 구조, 원본 바이트 가드, 중복 목적지, 종결자, 길이, 재파싱, 결정적 해시를 확인합니다.

D88과 KANJI1 ROM 각각의 원본·결과 차이를 IPS로 생성하고, 원본에 재적용해 빌드 결과와 대조합니다. 출력 폴더를 지정한 `verify`는 두 IPS도 검사합니다.
