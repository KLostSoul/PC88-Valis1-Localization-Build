# 컴포넌트 검토 패키지

원본 매체, 이벤트 블록 1~6, 게임오버, 엔딩, 로고·ERROR 07, 제어 토큰, KANJI1, 직접 기록기와 테스트가 재현 빌드의 주요 구성입니다.

| 패키지 | 검토 결과 |
|---|---|
| 원본 매체 | D88 구조·ROM 구조·해시 확정 |
| 이벤트 블록 1~6 | 행·제어값·종결자·실행/저장 위치·이전 바이트 확정 |
| 게임오버 | 고정·스크롤·marker·hold·이전 바이트 확정 |
| 엔딩 1~24 | 세그먼트·길이·종결자·보정 범위 확정 |
| 제어 토큰 | 실제 바이트열과 의미 확정 |
| KANJI1 | 글리프·토큰·슬롯·ROM 바이트 확정 |
| 로고·ERROR 07 | 로고 PNG와 source-map 설정·인코더·RAM-to-raw 매핑, ERROR 07 직접 변경표 확정 |
| 디버거 관찰 | 진입점·분기·여유 공간·관찰 바이트 기록 |

직접 바이트 컴포넌트는 변경표를 사용합니다. 로고는 `source/GFX/` PNG를 실제 입력으로 읽고 `source/tables/logo/source-map.csv`에서 주소·길이·크기·인코더를 가져옵니다. 기준 픽셀이 달라진 그룹을 재인코딩하고 검토된 RAM-to-raw 매핑으로 적용합니다. 원본 바이트가 맞지 않거나 이미지 메타데이터와 표가 불일치하면 빌드를 중단합니다.
