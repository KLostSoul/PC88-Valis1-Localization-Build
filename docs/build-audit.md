## 수정 사항

- 입력 선택을 SHA-256과 크기로 통일하고 파일명에 대한 거부 조건을 제거했다.
- 편집된 PNG를 빌드·검증할 수 있도록 현재 소스의 재빌드 결과와 대조한다.
- 이벤트 표의 잘못된 디코딩 메타데이터 11바이트와 문자·감사 표 표시를 정정했다. 블록 5 한국어 토큰의 발화 플래그도 실제 패치와 맞췄다.
- 확인할 수 없는 외부 문서 경로 5,685개를 제거하고, 근거 및 보고서의 참조를 저장소 파일에 맞췄다.
- ERROR 07의 혼합 의미 열을 제거하고 ASM 명령열과 raw 패치의 일치를 검사한다.
- 로고 PNG 여섯 장을 매 빌드 인코딩하고 8,163 source bytes를 RAM-to-raw 매핑으로 기록한다.
- 글리프 범위·토큰·경로, 이벤트 배열 정렬, 엔딩 토큰, 게임오버 주소·길이, 대기 바이트, 로고 RAM 매핑을 빌드 전에 검사한다.
- D88 크기·트랙·섹터 구조와 중복 쓰기를 검사한다. 잘못된 PNG 청크, 흑백이 아닌 픽셀, 인코더 범위 초과를 거부한다.
- 통합 빌드를 임시 위치에서 완성한 뒤 출력하며, 저장 실패 시 기존 결과를 복구한다. 원본 덮어쓰기를 거부한다.
- 검사 실패의 종료 코드, 미디어 제외 규칙, 실행 예제와 검증 문서를 수정했다.
